# 台幣匯率與生存必需品購買力分析｜TWD Living Cost

> 工程狀態：**v6.1 施工中 / NOT YET PRODUCTION-VERIFIED**。此專案剛完成 GitHub 初始化，尚未宣稱資料自動更新、網站正式上線或完整任務驗收。

## 任務

為台灣一般民眾、國中生及高齡使用者建立免登入、免安裝的公開網站：

- USD、JPY、EUR、CNY、GBP、AUD、KRW、SGD 兌 TWD，半年／1／3／5／10 年變化。
- 米、蛋、蔬果、水、電、燃氣、住宅租金等**台灣基本生活必需品**的官方項目物價指數。
- 僅在來源和日期可比時，計算外幣對實際生活必要支出的購買力。
- 區分 CPI 指數、零售實售價格、批發行情以及個人消費籃子估算。
- 使用來源有證據的市場解釋，**不得把新聞相關性說成已證明因果**。
- GitHub Actions 自動處理已核准可公開的資料，GitHub Pages 公開長者友善網頁。

## 發布前阻擋條件

1. 央行部分長期日匯率資料的底層來源含第三方行情，完整序列／衍生序列的公開再散布權利仍須確認；不得未經確認上傳完整歷史行情。
2. 官方 6563 舊 JSON API 有資料停在 2019 年的既知案例；不將 HTTP 200 當成新鮮數據證據。
3. 主計總處 CPI 來源只接受 `TYPE=原始值`，須以精確項目代碼、原始基期和同月對齊。
4. 公開資料觀測日必須可查；**不顯示模擬匯率當作實況**。
5. GitHub Pages 尚需由倉庫管理者設定一次，實際公開網址與資料讀回尚未驗收。

## 官方資料與標示

- [中央銀行 6563](https://data.gov.tw/dataset/6563) — 來源及再利用權利待釐清。
- [主計總處 9158](https://data.gov.tw/dataset/9158) — 消費者物價基本分類暨項目群指數，政府資料開放授權條款第 1 版。
- [農業部 8066](https://data.gov.tw/dataset/8066) — 農產**批發市場**交易行情，非零售價格。
- [國發會民生物價看板](https://price.ndc.gov.tw/p/zh_tw/necessities) — 只作官方連結，零售 SKU 機讀與授權尚待確認。
