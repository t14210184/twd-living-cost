## 任務

為台灣一般民眾、國中生及高齡使用者建立免登入、免安裝的公開網站：

- USD、JPY、EUR、CNY、GBP、AUD、KRW、SGD 兌 TWD，半年／1／3／5／10 年變化。
- 米、蛋、蔬果、水、電、燃氣、住宅租金等**台灣基本生活必需品**的官方項目物價指數。
- 僅在來源和月份可比時，計算外幣對個人可調整必要生活費籃子的購買力（已完成八項可選品項、支出權重、台幣／外幣兩種收入情境）。
- 區分 CPI 指數、零售實售價格、批發行情以及個人消費籃子估算。
- 使用來源有證據的市場解釋，**不得把新聞相關性說成已證明因果**。
- GitHub Actions 自動處理已核准可公開的資料，GitHub Pages 公開長者友善網頁。

## 資料新鮮度與比較方法

國際八幣歷史是美國聯準會 H.10 **紐約午間參考報價**，通常每週一更新前一週資料，非台灣即時換匯價格。最新資料日、原始檔 SHA-256、十年共同日數量與完整月數保存在 [manifest](site/data/manifest.json)。查詢網站會每 30 分鐘嘗試重新讀取已發布 JSON。

## 核心首頁：兩組真實參數對「生活感受」的差異

**使用步驟：** 選半年／1／3／5／10 年 → 選「固定台幣收入」或「每月固定可用外幣」 → 選參考貨幣 → 依家庭實際花費修改「米、蛋、蔬菜、乳類、房租、水、電、燃氣」八項金額。預設支出數字**只是為了打開即可操作的示範資料**，不是台灣家庭平均開支；官方真實性只涵蓋匯率與物價指數。

**同月核心模型：**
- `家庭本月開支 B_end = 各項本月使用者輸入支出之總和`
- `同樣消費組合過去估計開支 B_start = Σ(本月該項支出 × CPI_start/CPI_end)`
- `生活費變化 = B_end / B_start - 1`
- `固定台幣收入購買力變化 = B_start/B_end - 1`（假設兩期間固定同樣名目薪水，**匯率無直接收入效果**）
- `固定外幣金額購買力變化 = (FX_end/FX_start)/(B_end/B_start)-1`（忽略銀行價差、稅費；等額外幣不代表實際薪資未成長）
- 以完全一致的 CPI 與 H.10 完整月份起訖點比較，沒有共同資料時拒絕拼湊。各月由 `site/life_math.js` 算出帶有十年區間的三條 Index100 歷史線。

**不可混淆：** 國內必需品 CPI 已反映當時國內物價變化，但不能單憑匯率與 CPI 兩條線估出匯率變化導致了多少進口成本或一般物價變化；要研究因果須另加進口價格、供應鏈與事件證據。八項細項 CPI 也不等於所有家庭生存必需品，更不是指定超市實際成交價格。
